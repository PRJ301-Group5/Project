3. Website and .exe App Features
The Website/App will require account login if available, with sections for account creation and forgotten passwords. An OTP code will be sent to Gmail or a phone number for account creation and password recovery.
For Students:
• It will display the subjects assigned by the school, for example: Semester 1: ANC111, ABC222...
• Upon login, if there are subjects requiring assignment submissions, a notification will be displayed immediately.
For Lecturers:
• It will display tools to create classes, create assignments, and upload assignment prompts for students to download.
• There will be a section to grade each assignment submitted by students, featuring AI tools (requires API key). When the API key is entered, it will read the lecturer's prompt requirements and grade the assignment automatically. Additionally, it will analyze errors and summarize the assignment if necessary.
• Furthermore, there are sections for lecturer feedback/comments.
4. Tool and Feature Requirements
• Tools such as automatic deadline notifications, sending an email to the student's registered email if the deadline is approaching and no submission has been made.
